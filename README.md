🐾 Zoo Management System

A Zoo Management System desktop application built in Java using IntelliJ IDEA.
This project helps manage animals, enclosures, employees, and feeding schedules in a zoo.
📌 Features

🐯 Animal Management

Add, update, delete, and view animals

Track species, age, health status, and enclosure

🏠 Enclosure Management

Create and manage animal habitats

Assign animals to specific zones

🛠 Technologies Used

Language: Java

IDE: IntelliJ IDEA

Paradigm: Object-Oriented Programming (OOP)
